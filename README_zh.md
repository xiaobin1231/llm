追求技术的道路是泥泞的，但我始终怀有一腔热忱。

# 引言
性能优化，这个话题很大，要想好用不难，好到极致也不易。自底向上，从一个不那么专业的人士角度阐述自己的认知：
- 深入理解芯片结构是前提，支持跨平台的算子其性能不可能超越芯片的定制算子。当业界解决方案成熟稳定，商业模式跑通，ASIC必定迎来新一轮爆发。
- 如果把底层硬件比喻成拄着老人走路保障不摔倒的拐杖，那么系统架构一定是这位老人的大脑，他会做决策、做判断，在什么时间点，什么地方需要打车，需要换公交，花最少的钱最快达到目的地。异构芯片已经是AI的标配，搬运数据，并行计算，写回结果也是一套标准化流程。系统层面不做任何设计，即使模型能在芯片上跑起来，那也只是能跑，真正的商业落地还十分遥远。而系统架构的职责就是从全局角度编排调度，最大程度挖掘有限的硬件资源池，包括CPU/NPU/GPU/RAM等，让单次用户的请求尽快得到响应，又能同时支持多用户享受服务。
- 最上层的算法与模型可等价为行驶的交通工具，它是200匹的本田雅阁，还是1200匹的布加迪威龙，它是两轮摩托车还是沃尔沃，这些车型的选择决定你需要承受的安全风险以及时间用来赶路。根据具体的业务场景，数据与模型结构、参数量、量化精度等因素一定是被需要综合考虑。模型参数量指数级上升，量化剪枝蒸馏技术层出不穷，量化从业者的究极目标 ———— 低精度模型、高准确度结果，始终是难以逾越的大山。
- ......

直到有一天，flash attention横空出世，我怀着好奇心情拜读论文，迫切地想知道Tri Dao用了何种“神仙妙计”加速attention计算。论文看完，猛然惊醒，论文提到的技术方法是高度依赖一个自底向上都需要有深厚沉淀的团队才可突破的瓶颈，具有划时代的意义。不懂算法，就不会有online softmax；不懂系统，就不会想到流水线多阶段的优化，让数据搬运与计算并行；不懂芯片，TMA、TensorCore就只能乖乖躺在硅片里看戏。论文里提供的核心思想完美契合个人价值观，当梦想照进了现实，激动的心情溢于言表。
